# How to Run

## Requirements

* Java JDK installed
* VS Code or any Java-supported IDE

## Steps

1. Open the project folder in VS Code.
2. Open the terminal.
3. Go to the `src` folder:

```bash
cd src
```

4. Compile the Java files:

```bash
javac *.java
```

5. Run the application:

```bash
java PackerUnpackerGUI
```

The Java File Packer-Unpacker GUI will open.

## Note

The `.class` files generated during compilation are ignored by Git using `.gitignore`.
