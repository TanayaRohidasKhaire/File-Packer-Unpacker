# Java File Packer-Unpacker

A Java-based application used to **pack multiple files into a single file and unpack them when required**.

## Features

* Pack multiple files into one file
* Unpack files from the packed file
* XOR-based encryption and decryption
* Simple Java Swing GUI
* Java File Handling

## Technologies

* Java
* Java Swing
* File Handling
* XOR Operation
